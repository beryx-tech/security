# Security advisories for BeryX packages

This repository publishes the security advisories of the BeryX packages: the Python packages on PyPI (`beryx-sdk`, `beryx-airflow`, `beryx-profiler`), the BeryX extension for VS Code, the BeryX plugins for Claude Code and the BeryX provider for Terraform. It has no code.

## Report a vulnerability

Write to **security@beryx.tech**. Please do not open a public issue and do not publish details before the fix.

Tell us the package and its version, what you did, what happened and the impact you see. Never send your API token or your customers' data.

We acknowledge receipt within 3 business days and send a first assessment within 5. Our target time to fix is 7 days for a critical vulnerability, 30 for a high one and 90 for a medium one.

## Actively exploited vulnerabilities and severe incidents

If a vulnerability in one of these packages, or in the BeryX service they depend on, is being actively exploited, or if a severe incident affects their security, BeryxTech notifies CERT.PT and ENISA under Article 14 of Regulation (EU) 2024/2847 (Cyber Resilience Act). We tell affected users straight away, without waiting for the fix.

## Advisories

Advisories are published at <https://github.com/beryx-tech/security/security/advisories> on the day the fix ships, and straight away for an exploited vulnerability or a severe incident.
